The question, and ^report(18)'s answer

Cyrus asked, at his meeting with Matthew on 2026-10-16, why CI fails on #2635, the branch that merges modular editors (#2469) into the livelits branch (#2597). ^report(18) read all 97 of #2635's CI runs and found that it had never passed, failing the same tests every time, for three causes that came from the merge itself, with neither parent broken on its own:

  • 8 module tests: #2469 analyzes a module one member at a time on dev's module statics, which Modules II (on the livelits branch only) replaced, so the merge analyzed a module literal whole and the tests' counts came out low (cause 1);
  • 1 table test: dev's canonical completion (#2374) closes the stray bracket the test relied on, so its error no longer landed in a hidden row (cause 2);
  • 1 corpus test: one livelits document elaborated differently per item than as a whole program, cause unknown when the report was first written (cause 3).

Its update at 12:45 MDT the same day had a fix for each, and its What next listed five steps. This report takes them one by one.
